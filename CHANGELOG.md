# Changelog

## 2.0.0

- Replaced the MQTT bridge with a native Home Assistant custom integration.
- Preserved climate, heating switch, fixed-power select, forced-auger number,
  status sensors, state mappings, and immediate post-command refresh behavior.
- Added UI setup, validated options, stable serial-based identifiers, local
  brand assets, diagnostics, translations, HACS metadata, and automated checks.
- Kept the legacy add-on sources in the repository during the migration and
  test phase.
